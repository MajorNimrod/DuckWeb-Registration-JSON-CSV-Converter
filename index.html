How it works

This tool converts your DuckWeb registration data into a spreadsheet-friendly CSV.

1. Export from DuckWeb
  1. Open your weekly schedule / registration page
  2. Press F12 → Network tab
  3. Refresh page, filter by Fetch/XHR
  4. Right-click the JSON request → “Save all as HAR with content…”
2. Convert here
  1. Select your .har or raw .json
  2. Click Convert to CSV
  3. Open the downloaded schedule.csv in Excel / Sheets
What this does:
  • Groups by CRN (one row per course)
  • Filters out long exam-style blocks (>= 119 minutes)
  • Cleans titles like + Dis / + Lab so Excel doesn’t treat them as formulas
  • Formats times like Mon 1:00 PM-1:50 PM
